# KAN-6 sample GIS data

This folder contains source references and reproducible outputs for the historical TP.HCM 2D OSM dataset (boundary before 2025-07-01).

- `source/`: OSM boundary input generated by the cloud workflow and source-data notes.
- `processed/`: generated GeoJSON boundary, building footprints, and automated quality summary.
- The source Vietnam PBF and temporary clipped PBF are not committed to Git.

## Run in GitHub Actions (no local GIS installation required)

1. Open the repository on GitHub and select branch `task/p1-04-gis-data-model-sample-data`.
2. Open **Actions** and select **KAN-6 - Prepare HCMC OSM sample data**.
3. Select **Run workflow**, confirm `old-hcmc`, and start the run.
4. Wait for the job to finish. A successful run uploads artifact `kan-6-hcmc-old-osm-data`.
5. Open the completed run and download the artifact from the **Artifacts** section. The ZIP contains the GeoJSON layers, checksums, and automated quality summary.

The workflow uses GitHub-hosted Ubuntu, downloads the Geofabrik Vietnam PBF, resolves the pinned OSM administrative relation 1973756, clips the PBF with Osmium, and processes buildings with GDAL/OGR. The artifact is retained for 30 days.

> GitHub only enables `workflow_dispatch` for a workflow once its workflow file exists on the repository's default branch. If the workflow does not appear in the Actions tab while it exists only on this task branch, create/review a PR and merge the workflow file to the default branch first; then choose this task branch as the run ref. Do not merge the task branch wholesale unless that is intended.

## Data and licensing notes

- Output format: GeoJSON RFC 7946 / WGS 84 longitude-latitude (EPSG:4326).
- Building layer contains 2D OSM building footprints only. Height, floors, population, occupancy, and epidemiological attributes are not inferred.
- Attribution: © OpenStreetMap contributors, ODbL.
- OSM is community-maintained and may be incomplete; automated QA does not replace visual review in QGIS.

Do not commit large PBF or generated GeoJSON files to Git. Use the Actions artifact as the data handoff to KAN-13/KAN-14.
