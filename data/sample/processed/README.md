# Processed GIS data

The following files are generated by `scripts/gis/prepare_osm_data.sh` after source inputs have been verified:

- `hcm_boundary.geojson`: normalized HCMC study boundary.
- `hcm_buildings.geojson`: OSM building footprints clipped to that boundary.

Both outputs use GeoJSON RFC 7946 coordinates (WGS 84 longitude/latitude, EPSG:4326). Building geometries are promoted to MultiPolygon without intentionally reducing their spatial extent.

These outputs are not committed until generated from real OSM inputs and validated. Do not create placeholder features or report unmeasured feature counts.
